# P4 Agent Sandbox Roadmap

## M1 Runtime Foundation
完成 FastAPI API、Orchestrator、SafeToolExecutor、Tool Registry、TaskStore、Audit、Sandbox 和 File Tools。

## M2 Knowledge Runtime
完成 File Parsing、Knowledge Index、Incremental Build、Summary Search 和 Full Text Search。

## M2.5 Semantic Retrieval Runtime
完成 Chunking、Embedding、Vector Index 和 Semantic Search。

## M3 RAG Runtime
完成 Retrieval、Context Assembly、LLM Reasoning、Answer Generation、Source Attribution 和 Debug/User Mode。

## M4 Agent Intelligence
目标是实现 LLM Planner、Multi-step Tool Use、Reflection/Verification 和 Rule-based Planner Fallback。

## M5 Agent Memory
目标是实现 Session Memory、Persistent Memory、User Preferences 和 Task History Reuse。
