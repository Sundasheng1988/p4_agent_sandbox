# Agent Glossary

## Runtime
Runtime 是程序在运行过程中负责执行、调度、资源管理与结果返回的一整套机制。

## Knowledge Runtime
Knowledge Runtime 是系统围绕文档解析、知识索引、全文搜索与摘要检索形成的运行机制。

## Semantic Runtime
Semantic Runtime 是系统通过 embedding、向量索引和相似度计算来进行语义检索的运行机制。

## RAG
RAG 是 Retrieval Augmented Generation 的缩写，表示先检索知识，再将检索结果作为上下文提供给大模型生成答案。

## Chunk
Chunk 是从长文档中切分出来的较小文本片段，用于索引、检索和向量化。

## Embedding
Embedding 是将文本映射为数值向量的过程，使系统可以按语义相似度比较文本。
